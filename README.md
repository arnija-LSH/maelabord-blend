# Mælaborð BLEND

Mánaðarleg mælaborð fyrir BLEND/KG-svið Landspítala: fjárhagur, yfirvinna, stöðugildi og lyfjakostnaður.

**Opna appið:** https://arnija-lsh.github.io/maelabord-blend/

| Mappa eða skrá | Innihald |
|---|---|
| `index.html` | Appið sjálft (flipar og tímabilsval) |
| `dashboards/` | Mælaborðin fjögur |
| `data/<mánuður>/` | Samanteknar tölur hvers mánaðar |
| `app/` | Hleður gögnum valins mánaðar |
| `scripts/`, `Uppfaera.ps1` | Skriftur sem búa til `data/` úr Excel-skrám mánaðarins |

Leiðbeiningar um mánaðarlega uppfærslu eru í [Leiðbeiningar.md](Leiðbeiningar.md).
